## 1. Введение

ИИ-Агент СМК — это автономный ассистент, который помогает работать с документами Системы Менеджмента Качества предприятия. Агент:

- отвечает на вопросы по стандартам, регламентам и процессам компании, опираясь на внутреннюю базу знаний;
- читает, редактирует и создаёт документы Word и Excel;
- расшифровывает аудиозаписи совещаний и аудитов;
- строит блок-схемы и диаграммы;
- ищет информацию в интернете и Википедии (с вашего разрешения);
- ведёт корпоративную память важных фактов.

Агент не выдумывает регламенты: если в базе нет подтверждающего документа, он честно сообщает об этом и не даёт ответ на основе догадок.

---

## 2. Системные требования

- **ОС:** Windows 10/11 (64-бит).
- **Сеть:** доступ к корпоративному серверу с базой знаний и доступ к OpenRouter (для работы нейросетей).
- **Права:** для установки — права пользователя; для голосового ввода и интеграции с Outlook — установленный Microsoft Office/Outlook.
- **Звук (опционально):** микрофон для голосового ввода.
- **Место на диске:** ~1 ГБ под локальный профиль и теневую копию базы.

## 3. Установка на рабочее место

Установка выполняется с сетевой папки сервера одним двойным кликом:

1. Откройте сетевую папку Агента на сервере.
2. Дважды кликните файл **«Установить Агента СМК на ПК.bat»**.
3. Скрипт:
   - скопирует файлы программы в локальную папку профиля (`%LOCALAPPDATA%\SMK_Agent_Client_...`);
   - скопирует утилиты `ffmpeg`/`ffprobe` (для работы с аудио);
   - создаст **умный ярлык** на Рабочем столе с именем вида «ИИ-Агент СМК (ИмяБазы)».
4. По завершении нажмите любую клавишу.

> Установка не удаляет базы данных и хранилища на сервере. Повторный запуск скрипта обновляет клиентскую копию (режим зеркала).

## 4. Запуск приложения

- Дважды кликните ярлык **«ИИ-Агент СМК (…)»** на Рабочем столе.
- Ярлык запускает приложение с флагом `--server`, который указывает на серверную папку с базой знаний. Таким образом каждый ярлык привязан к своей базе.
- Приложение создаёт **изолированный профиль** в `%LOCALAPPDATA%\SMK_Agent_<хэш>` и работает с теневой копией базы на локальном SSD — это ускоряет работу и защищает серверную базу.
- При первом запуске в строке состояния отображается «Загрузка…», затем — «База готова (чанков: N)».

## 5. Интерфейс приложения

Окно делится на **боковую панель** (слева) и **область чата** (справа). Номер версии отображается в заголовке окна.

### Боковая панель

Панель зафиксирована по ширине и сгруппирована в три секции.

**СЕССИЯ**

| Элемент | Назначение |
|---------|-----------|
| **Очистить чат** | Начинает новый диалог, сохраняя предыдущий в историю. |
| **История диалогов** | Открывает список сохранённых сессий (только для админа). |
| **Экспорт в Word** | Сохраняет текущий диалог в `.docx` с тем же оформлением, что и в чате. |

**СИСТЕМА**

| Элемент | Назначение |
|---------|-----------|
| **Настройки** | Открывает окно параметров (см. раздел 16). |
| **Управление памятью** | Редактор корпоративной памяти (только для админа, см. раздел 13). |
| **Войти как Админ / Выйти (Админ)** | Переключение роли (см. раздел 6). |

**РЕЖИМЫ**

| Элемент | Назначение |
|---------|-----------|
| **Автономное чтение файлов** | Тумблер (админ): разрешает/запрещает агенту читать файлы без спроса (см. 17). |
| **Глубокий аудит (Рефлексия)** | Тумблер: включает проверку ответа моделью-аудитором (см. 17). |

Внизу панели — индикаторы: прогресс-бар синхронизации, имя обрабатываемого файла, статус базы, статус построения графа.

### Область чата

- **Окно сообщений** — отображает диалог: ваши сообщения и ответы агента. Поддерживается полноценное форматирование: заголовки, **жирный**, *курсив*, ~~зачёркнутый~~, `код`, блоки кода в виде «карточек» на подложке, таблицы, списки и чек-листы (☑/☐), цитаты, разделители, мелкий текст. Оформление чата автоматически подстраивается под светлую/тёмную тему Windows без перезапуска.
- **Кликабельные ссылки** — упоминания документов выводятся в виде `[Из файла: ...]`. Клик открывает файл (для гостя — безопасную копию во временной папке, для админа — оригинал); поиск файла выполняется в фоне и не блокирует окно. Если файл не найден, агент предложит похожие имена. Веб-ссылки открываются в браузере.
- **Поле ввода** — многострочное: растёт по мере набора текста (до ~6 строк), справа отображается счётчик символов. Пока поле пустое, в нём виден подсказывающий текст. `Enter` — отправить, `Shift+Enter` — перенос строки.
- **Кнопки ввода**:
  - **📎 Скрепка** — прикрепить файлы к чату.
  - **🎤 Микрофон** — голосовой ввод (Push-to-Talk), только для админа.
  - **📝 Промпт-мастер** — конструктор запросов по шаблону.
  - **➤ Отправка** — отправить сообщение. Во время работы агента кнопка превращается в **⏹ Стоп** (см. раздел 7).

## 6. Роли: Гость и Администратор

Приложение работает в двух ролях. Роль определяет доступные функции и используемую модель.

| Возможность | Гость (по умолчанию) | Администратор |
|-------------|----------------------|---------------|
| Вопросы по базе знаний | Да | Да |
| Чтение и правка документов | Да | Да |
| Генерация документов и схем | Да | Да |
| Прикрепление аудио и изображений | Нет | Да |
| Голосовой ввод (микрофон) | Нет | Да |
| История диалогов | Нет | Да |
| Управление памятью (окно) | Нет | Да |
| Синхронизация базы | Нет | Да (окно «Настройки», панель обслуживания) |
| Выбор провайдера основной модели | Да (без «Другой…») | Да |
| Вкладки «Безопасность», «Аудио/Сеть», «Rerank», «Графы» | Скрыты | Доступны |
| Глубокий аудит (рефлексия) | Включён принудительно | По выбору |

### Вход в режим администратора

1. Нажмите **«Войти как Админ»** на боковой панели.
2. Введите пароль администратора в диалоговом окне.
3. При успехе появится сообщение «Текущая роль: Admin», кнопка сменит подпись на **«Выйти (Админ)»**.
4. Для выхода — нажмите ту же кнопку.

> Пароль по умолчанию — `admin`. Рекомендуется сменить его в настройках (вкладка «Безопасность»).

## 7. Как правильно задавать вопросы

Агент следует строгому алгоритму: **сначала сверяется с локальной базой знаний**, и только потом действует.

- **Конкретные вопросы** формулируйте предметно: «Какие этапы процесса найма сотрудника?», «Что регламентирует СТО СМК.031.20?».
- Агент укажет источник в виде ссылки `[Из файла: ...]` — кликните её, чтобы открыть документ.
- **Если в базе нет ответа**, агент не станет выдумывать. Он спросит, где искать: в интернете (Tavily) или в Википедии. Выберите источник — ответ будет с прямыми веб-ссылками.
- **Ссылки на номера ответов**: каждое сообщение нумеруется. Если вы ссылаетесь на старый ответ («как мы обсуждали в ответе №3»), агент найдёт его по внутренней метке.
- **Стиль ответа**: при включённом «Глубоком аудите» черновик проверяется второй моделью — из ответа удаляются неподтверждённые утверждения.

### Лимит шагов и кнопка Стоп

Сложные запросы агент выполняет циклом «поиск → размышление → инструмент», тратя на каждый цикл один шаг:

- Лимит шагов задаётся на вкладке **«Модели»** — ползунок **«Макс. шагов цикла поиска/размышления»** (5–60, по умолчанию 25). Для работы с большими Excel-таблицами действует отдельный, более щедрый лимит.
- Пока агент работает, кнопка отправки превращается в **⏹ Стоп**. Нажатие останавливает работу: агент соберёт итог из уже найденного, пометит ответ строкой «собран по частичным данным» и перечислит, что осталось непроверенным.
- При исчерпании лимита шагов происходит то же самое — вместо бесконечного ожидания вы получаете сводку по частичным результатам.
- Если агент начинает повторять одни и те же действия, он предупредит об этом, а после третьего повтора сам завершит работу со сводкой.

## 8. Работа с документами Word

### Чтение
- Попросите: «Прочитай файл РК СМК.001.20» или «Что в документе План внутреннего аудита?» — агент вызовет чтение файла.
- При выключенном «Автономном чтении файлов» агент сначала спросит разрешения: «Мне прочитать файл [Имя]?» — ответьте «Да».
- **Картинки внутри документов** распознаются Vision-моделью (сканы, схемы, фотографии страниц) — агент «видит» их содержимое. Лимит изображений на документ настраивается на вкладке «XWiki» (админ).
- **Большие документы** (более ~100 тысяч символов) не вставляются в чат целиком: агент читает и обрабатывает их программно, через Python.

### Комментарии рецензентов
- Если в документе или таблице есть **комментарии** (Word, Excel), при прикреплении файла агент сообщит об этом. Попросите «прочитай комментарии к файлу» — агент покажет их с указанием места, автора и даты.

### Правка существующего документа
1. Опишите, что нужно изменить: «В документе X замени раздел 3 на новый текст».
2. Агент прочтёт файл, покажет предложенные правки и попросит согласие.
3. После слова «Согласен» / «Да» правки применяются массово по индексам абзацев.

### Создание документа по образцу
- «Составь новый план аудита на основе файла План_аудита_старый.docx». Агент использует структуру-шаблон и подставит новые данные.

### Создание документа с нуля
- «Разработай новую инструкцию по управлению несоответствиями». Агент сгенерирует структуру и текст нового документа.
- При необходимости можно указать файл-референс для копирования стилей и шапки.

## 9. Работа с таблицами Excel

По умолчанию агент работает с **журналом регистрации результатов аудитов** (имя задаётся в настройках).

### Поиск записей
- «Найди открытые несоответствия по процессу управления персоналом».
- Агент выполнит семантический поиск по таблице и вернёт подходящие строки.

### Добавление/обновление записей
1. Агент сначала ищет контекст (старые записи).
2. Показывает результаты и просит согласие.
3. После согласия вносит изменения (например, меняет статус на «Выполнено» или добавляет новую строку).

### Анализ больших таблиц
- Для крупных Excel-файлов агент может выполнить Python-код с pandas: «Посчитай, сколько открытых и выполненных записей в журнале».

### Старый формат .xls и скрытые листы
- Файлы старого формата **`.xls`** теперь тоже работают: их можно прикреплять к чату, и они индексируются в базу знаний. Конвертация выполняется автоматически и кэшируется — повторное обращение к тому же файлу мгновенно.
- **Скрытые листы** Excel в базу знаний не попадают и в поиске не участвуют — индексируются только видимые листы.

> Статусы «Открыто»/«Выполнено» и колонка-признак настраиваются в разделе «Настройки Excel».

## 10. Генерация схем и диаграмм

Агент строит схемы в двух форматах:

- **yEd GraphML** (`.graphml`) — полноценные блок-схемы с узлами, группами, связями и типами потоков (материальный/информационный). Открывается в редакторе yEd.
- **Mermaid** (`.html`) — диаграммы и mindmap, открываются в браузере.

Порядок:
1. Опишите схему: «Построй блок-схему процесса входного контроля».
2. Если формат не указан явно, агент спросит: «Какой формат нужен — yEd GraphML или Mermaid?»
3. После выбора файл создаётся в папке созданных документов, а ссылка выводится в чат.

## 11. Аудио: транскрибация и голосовой ввод

### Транскрибация аудиофайла
- Аудиофайлы (`.mp3`, `.wav`, `.m4a`) должны находиться в индексируемых папках базы.
- Попросите: «Проанализируй запись совещания recording.mp3».
- Если расшифровки ещё нет, агент спросит разрешения: «Запустить расшифровку голоса в текст?» — ответьте «Да».
- Процесс долгий и платный: аудио режется на чанки с перекрытием, распознаётся нейросетью (Whisper), результат сохраняется в Word-документ. Повторное чтение берёт текст из кэша без повторной расшифровки.

### Голосовой ввод (только админ)
- **Зажмите и удерживайте** кнопку микрофона (Push-to-Talk) или используйте горячую клавишу (по умолчанию `Ctrl+G`).
- Говорите сообщение, затем отпустите — аудио расшифруется и подставится в поле ввода.
- Горячую клавишу и микрофон можно настроить в разделе «Аудио/Сеть».
- Голосовой ввод работает и при русской раскладке клавиатуры.

## 12. Прикрепление файлов к чату

1. Нажмите кнопку-скрепку в панели ввода.
2. Выберите один или несколько файлов.
3. Файлы появятся в виде «чипов» над полем ввода (наведите курсор — увидите полное имя).
4. Отправьте запрос: «Проанализируй прикреплённый документ» — агент прочитает именно вложение.

**Поддерживаемые форматы:**

| Роль | Форматы |
|------|---------|
| Гость | `.txt`, `.md`, `.docx`, `.doc`, `.rtf`, `.pdf`, `.xlsx`, `.xls`, `.csv`, `.graphml`, `.html` |
| Админ | Все перечисленные + `.jpg`, `.jpeg`, `.png`, `.bmp`, `.mp3`, `.wav`, `.m4a`, `.ogg`, `.flac` |

> - Прикреплённый файл читается отдельным инструментом и не требует добавления в базу знаний.
> - **Комментарии** из docx/xlsx подхватываются автоматически (см. раздел 8).
> - **Картинки внутри docx** распознаются Vision-моделью.
> - **Большие Word/Excel-файлы** агент обрабатывает программно — в чат вставляется маркер «большой файл», а сам файл читается по частям.

## 13. Память и история диалогов

### Корпоративная память (админ)
- «Запомни: в процессе X ответственный — Иванов И.И.» — факт сохранится в файл памяти с датой.
- «Забудь факт про X» — запись удалится, база переиндексируется.
- Все факты доступны через обычный поиск по базе знаний.

### Окно «Управление памятью» (админ)
- Кнопка **«Управление памятью»** открывает редактор файла корпоративной памяти: можно просмотреть все накопленные факты, отредактировать или дописать их вручную.
- При сохранении автоматически создается **страховочная копия** предыдущей версии, а база переиндексируется в фоновом режиме.
- Перед перезаписью изменений, сделанных агентом в фоне, окно предупредит и попросит подтвердить.

### Отзыв старых деталей диалога
- Агент помнит последние ~20 сообщений. Если вы ссылаетесь на детали более ранних реплик («как мы решали ту проблему?»), он вызовет поиск по прошлому диалогу.

### История диалогов (админ)
- Кнопка **«История диалогов»** открывает список сохранённых сессий.
- Выберите сессию, чтобы продолжить или просмотреть. Сессии можно переименовать (✏️) или удалить (🗑). Удалённые сессии стираются вместе с их векторной историей.

### Экспорт диалога
- Кнопка **«Экспорт в Word»** сохраняет текущий диалог в `.docx` (имя по умолчанию — название сессии). Экспорт сохраняет то же форматирование, что видно в чате: заголовки, таблицы, жирный/курсив, код, списки.

### Очистка
- Кнопка **«Очистить чат»** завершает текущий диалог и начинает новый; старый сохраняется в историю.

## 14. Промпт-мастер (конструктор запросов)

Кнопка-карандаш в панели ввода открывает модальное окно для конструирования сложных запросов:

- **Шаблоны** — выберите сохранённый шаблон из списка или создайте новый.
- **Параметры запроса** — короткие и длинные поля (тема, даты, ФИО, процесс и т.п.).
- **Сохранить / Удалить** — управление шаблонами; хранятся в локальном профиле.
- Сформированный запрос отправляется в чат одной кнопкой.

> Удобно для повторяющихся задач: аудитов, протоколов, регулярных отчётов.

## 15. Синхронизация базы знаний

Синхронизация обновляет векторную базу при появлении новых или изменённых документов. Кнопки синхронизации находятся в окне **«Настройки»** (внизу, панель обслуживания) и доступны только администратору:

- **«Синхронизировать базу»** — быстрая синхронизация: пересканирует только индексируемые папки (дельта по дате изменения файлов), проверяет целостность графа и выгружает изменения на сервер.
- **«Синхронизировать XWiki»** — полная синхронизация: дополнительно скачивает и обновляет страницы корпоративной вики (включая вложения и диаграммы), после чего объединяет всё в базу. Без неё новое с вики не попадёт в поиск.

Особенности:

- Если задан **пароль синхронизации** (вкладка «Безопасность»), перед запуском он будет запрошен.
- Запущенная синхронизация не может начаться повторно, пока не завершится предыдущая (в том числе фоновая) — кнопка просто сообщит «Синхронизация уже выполняется».
- Выгрузка на сервер выполняется **дельтой** (только изменённое), поэтому завершение синхронизации занимает заметно меньше времени, чем раньше.
- Во время синхронизации построение графа связей ставится на паузу и возобновляется автоматически.
- Прогресс отображается в боковой панели: прогресс-бар и имя обрабатываемого файла.
- Глубина «паучьей догрузки» страниц вики (переход по ссылкам с discovered-страниц) настраивается на вкладке «XWiki» (см. раздел 16).

## 16. Окно настроек

Открывается кнопкой **«Настройки»**. Вкладки:

> - У каждой модели на вкладке «Модели» есть выбор из актуального каталога провайдера; у гостя доступны только бесплатные модели (для OpenRouter — с суффиксом `:free` и аналогичные).

## 17. Тумблеры режима работы

### Автономное чтение файлов (админ)
- **Включено** — агент сам читает нужные файлы для ответа.
- **Выключено** — агент обязан спросить разрешения перед чтением каждого файла целиком и дождаться «Да». Используйте, если хотите контролировать обращения к документам.

### Глубокий аудит (Рефлексия)
- **Включено** — черновик ответа проверяется второй моделью-аудитором: удаляются галлюцинации, проверяются факты по контексту, блокируются ответы по регламентам при отсутствии подтверждающих документов.
- Для **гостя** тумблер включён принудительно и не отключается.

## 18. GraphRAG (граф связей)

При включённом GraphRAG (вкладка «Графы», админ) агент дополнительно строит и использует граф связей СМК:

- сущности и отношения извлекаются из документов нейросетью в фоновом режиме;
- дубликаты сущностей объединяются по семантической близости;
- `.graphml`-схемы индексируются напрямую в граф;
- агент применяет граф для вопросов об иерархии, подчинении и структуре процессов;
- связи выдаются **по уровню подтверждения**: сначала те, где обе сущности найдены в чанке дословно (с цитатой-подтверждением), затем частичные совпадения, затем неподтверждённые — и только потом схемы;
- устаревшие привязки рёбер (после переименования файлов) лечатся автоматически.

Статус построения отображается в боковой панели отдельной строкой. GraphRAG — дополнение к текстовому поиску, а не его замена.

## 19. Безопасность и ограничения

- **Ключи API** хранятся в зашифрованном Vault (Fernet), а не в открытом виде. Fallback — переменная окружения `OPENROUTER_API_KEY`.
- **Гость** не может изменять базу, синхронизировать, использовать память и работать с аудио/изображениями.
- **Открытие файлов гостем** происходит через безопасную копию во временной папке — оригиналы не затрагиваются.
- **Запрет на выдумывание регламентов**: при пустом контексте агент блокирует ответ и просит уточнить запрос или загрузить документ.
- **Согласие на действия**: платные/долгие операции (транскрибация, правки Excel, генерация документов) выполняются только после явного согласия.
- **Согласие на внешние источники**: интернет-поиск и поиск в Википедии запускаются только после вашего выбора.

## 21. Частые вопросы и устранение неисправностей

**Агент отвечает «не нашёл в базе знаний». Что делать?**
Убедитесь, что нужный документ добавлен в индексируемую папку и выполнена синхронизация базы (админом, кнопка «Синхронизировать базу» в настройках). Проверьте, что имя файла не содержит ключевых слов-исключений.

**Синхронизация долго идёт или «Ошибка БД».**
Закройте другие копии приложения (база может быть занята). Проверьте доступность серверной папки. Перезапустите приложение — при запуске база автоматически реплицируется с сервера. Если запущена другая синхронизация, новая стартует только после её завершения.

**Скачал страницу в вики, а агент её не видит.**
Полная синхронизация XWiki не была запущена — быстрая «Синхронизировать базу» страницы вики не качает. Нажмите «Синхронизировать XWiki» в настройках.

**Аудио не записывается / горячая клавиша не работает.**
Голосовой ввод доступен только в роли админа. Проверьте выбор микрофона и горячую клавишу в разделе «Аудио/Сеть». Убедитесь, что `ffmpeg.exe` скопирован в папку приложения.

**Файл по ссылке не открывается.**
Файл мог быть перемещён или удалён. Проверьте, что он присутствует в разрешённых директориях; агент предложит похожие имена. Для гостя открывается копия во временной папке — при проблемах проверьте права на `%TEMP%`.

**Ответы выглядят неотформатированными.**
Форматирование зависит от модели. Убедитесь, что выбрана подходящая модель во вкладке «Модели». Включение «Глубокого аудита» повышает строгость и достоверность ответов.

**Агент остановился сам и пишет «собран по частичным данным».**
Был исчерпан лимит шагов (или нажата кнопка ⏹). Увеличьте ползунок «Макс. шагов цикла» на вкладке «Модели» и повторите запрос, либо уточните вопрос, чтобы агенту требовалось меньше поисков.

**Приложение не запускается после обновления.**
Удалите локальную папку профиля `%LOCALAPPDATA%\SMK_Agent_Client_...` и повторно запустите установщик с сервера. Локальный профиль пересоздастся автоматически.

## 22. Поддержка

При возникновении проблем, не описанных в данном руководстве:
- обратитесь к администратору базы знаний СМК;
- при сообщении об ошибке приложите текст из строки состояния и название файла/операции, на которой произошёл сбой;
- подробный журнал работы доступен администратору: окно «Настройки» → кнопка «Логи» (и «Диагностика» для самопроверки).

Документ соответствует версии продукта **v2.7.2 Enterprise**. При обновлении приложения сверьтесь с актуальной версией руководства.
